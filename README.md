# Oracle ONE - Message Encryption and Decryption

This repository contains the project developed during the **first stage of the Oracle ONE course**, a partnership between **Alura** and **Oracle**. The challenge was to program a web page with an interface to encrypt and decrypt messages. **Alura** provided the layout of the interface in **Figma**, and the challenge focused on styling and programming the application's logic.

## Technologies Used

- **HTML**: Structuring the page content.
- **CSS**: Styling the page with a focus on responsive design.
- **JavaScript**: Implementing the encryption and decryption logic, DOM manipulation, and user interaction.

## Challenge Objectives

The challenge was designed to assess my skills in the following areas:

- **Responsive Design**: Ensuring the interface adapts well to different screen sizes.
- **Web Page Development with HTML, CSS, and JavaScript**: Creating a functional and well-structured page.
- **Programming Logic**: Correctly implementing the logic for encrypting and decrypting messages.
- **DOM Manipulation with JavaScript**: Interacting dynamically with the page elements.
- **JavaScript Language Mastery**: Demonstrating advanced knowledge of JavaScript to solve the proposed problem.

1. Clone the repository:
    ```bash

    ```

2. Navigate to the project folder:
    ```bash
    cd challenge-alura-oracle-one-01
    ```

3. Open the `index.html` file in your browser to view and interact with the page.
